# BARBER HOUSE — Modern Website

Website me shumë faqe i ndërtuar me HTML, CSS dhe JavaScript të pastër.

## Faqet
- `index.html` — kryefaqja
- `services.html` — shërbimet dhe çmimet
- `gallery.html` — galeria
- `about.html` — rreth nesh
- `contact.html` — orari, kontaktet dhe formulari i rezervimit

## Si ta hapësh
1. Shkarko ZIP-in dhe zgjidh Extract All.
2. Hape dosjen në Visual Studio Code.
3. Hape `index.html` në shfletues ose instalo Live Server në VS Code dhe përdor Open with Live Server.

## Para publikimit
- Ndrysho emrin Barber House në emrin real.
- Ndrysho numrin e telefonit, WhatsApp-in, adresën, email-in dhe orarin te `contact.html`.
- Ndrysho `whatsappNumber` në `js/main.js` në numrin real, pa + dhe pa hapësira.
- Përditëso çmimet te `services.html`, `index.html` dhe opsionet e formularit te `contact.html`.
- Zëvendëso fotografitë demonstrative me fotografi që ke të drejtë t'i përdorësh.

## GitHub Pages
1. Krijo një repository, p.sh. `barber-house`.
2. Ngarko të gjithë skedarët dhe dosjet duke ruajtur strukturën.
3. Shko te Settings → Pages.
4. Zgjidh Deploy from a branch, branch `main`, folder `/ (root)` dhe kliko Save.
5. Përdor adresën publike që të jep GitHub Pages.

## Shënime teknike
- Projekti nuk ka backend ose bazë të dhënash.
- Formulari përgatit mesazh në WhatsApp; nuk konfirmon automatikisht termin.
- Fotografitë dhe fontet nga shërbimet e jashtme kërkojnë internet.
